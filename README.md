# LunaTV 资源订阅（MoviePilot V3）

独立的 MoviePilot V3 插件，读取 MoonTV/LunaTV 的 `api_site` 配置，接入标准苹果 CMS V10 资源站。

## 当前范围

- 读取可配置的 LunaTV JSON 配置地址；默认使用个人可维护的配置仓库。
- 默认读取订阅地址内的全部资源站，单个源失败不阻塞其它源；只有显式填写旧版白名单时才过滤。
- 插件工作台将资源站列为“状态、资源名称、网址、搜索功能”四列；状态仅依据源配置备注，不表示实时测速。
- 使用 MoviePilot 活跃订阅名称搜索资源。
- 参与 MoviePilot 原生全局搜索与资源搜索，不再注册重复的 `LunaTV / 苹果 CMS` 探索标签；结果带有稳定的 `lunatv` 媒体身份，可继续创建订阅。
- 电视剧资源按“来源 + 季”显示为一个原生资源卡片；点击季卡片后，插件再按集串行排队。电影仍是一部一个资源项，多来源不会被同一播放地址误合并。
- 任务严格串行执行，不启动并行下载。
- 支持 m3u8/HTTP 资源下载到指定目录，或生成 `.strm`。
- 默认调用 MoviePilot 原生整理链；插件只在宿主链不可用时保留直写结果，完成记录统一回到 MoviePilot 原生历史。
- 下载完成后沿用 MoviePilot 已启用媒体服务器设置触发媒体库刷新；播放不放在插件页，仍由既有媒体服务器页面负责。
- 原生下载管理会投影插件任务的季集、可用时的 VOD ffmpeg 进度、暂停/继续和删除操作；暂停或删除运行中任务会先安全终止当前 ffmpeg，不把虚拟任务转发给 qBittorrent。
- 订阅刷新同时检查 MoviePilot 原生 TMDB 下载历史；即使整理方式移动了下载源文件，已经完成的电影或电视剧季集也不会被再次排队。
- 自动复用 MoviePilot“智能助手配置”（DeepSeek 等 OpenAI 兼容模型）清理片名后再搜索；未配置或调用失败自动回退原名称。
- 搜索结果自动调用 MoviePilot 原生识别链关联 TMDB；TMDB 能提供完整季集数时，会帮助拆分平铺的多季合集。
- 搜索结果会显示默认 TMDB 关联；同名或多季作品可重新搜索候选并手动切换，所选作品的季集数会参与安全拆分。
- 插件设置只保留一个下载目录，默认 `/downloads/未整理`；LunaTV 的 m3u8 下载统一优先写入该暂存目录。
- 任务通知通过 MoviePilot 插件消息能力发送；MoviePilot 的媒体库扫描可以继续接管已完成文件。

## 目录与命名

下载目录默认使用 `/downloads/未整理`。该路径必须在 MoviePilot 容器内存在且可写；下载完成后继续交给 MoviePilot 原生整理链，媒体库目录和整理规则无需在插件中重复配置。

```text
电影名 (年份)/电影名 (年份).mp4
剧名 (年份)/Season 01/剧名 (年份) - S01E01.mp4
```

下载先写入 `.part`，成功后再改为正式文件名，避免媒体库扫描到半成品。目录内没有正在下载的缓存文件时，媒体库才会显示完整文件夹；MoviePilot/Emby 的自动监控建议在确认前暂时关闭。

M3U8 VOD 下载会按 `N_m3u8DL-RE v0.5.1-beta → vsd 0.5.0 → ffmpeg` 依次回退。前两个引擎按需从官方 release 下载到插件数据目录的受控 `bin/`，流式校验固定 SHA-256 后才原子安装；每次运行前都会重新校验受管二进制，不使用 PATH 中的同名程序。N_m3u8DL-RE 支持 Linux x86_64/aarch64 与 macOS x86_64/arm64；VSD 支持 Linux x86_64/aarch64 和 macOS arm64，macOS x86_64 会直接跳过 VSD。暂停、失败和重启恢复会保留同一任务的专用缓存以便续传；仅成功或删除任务才清理缓存。所有引擎都不可用或失败时保留现有 ffmpeg 行为。

同一集只会进入一次队列；队列每次只执行一个任务，不会并行下载；MoviePilot 重启后会把中断中的任务恢复为待处理。详情接口缺少播放地址时，插件会自动补查 Apple CMS `ac=detail`，并识别 `S01E01`、`第 8 集`、`第 1 季` 等标记。只有线路或 TMDB 季集数能确定边界时才会按季聚合 `1-8 季`，无法确认时才退回单集，避免静默错放。

## 配置

默认配置地址：

```text
https://raw.githubusercontent.com/hafrey1/LunaTV-config/main/LunaTV-config.json
```

建议先只启用自己确认可用、且有权访问的资源源。插件不会绕过 DRM、登录保护或付费限制。

使用顺序：在插件卡片里保存订阅地址、下载目录并启用原生桥接 → 使用 MoviePilot 顶部全局搜索查找媒体并进入原生详情页 → 通过“搜索资源”或原生订阅触发 LunaTV 资源匹配 → 资源统一下载到暂存目录 → 下载完成后由 MoviePilot TMDB 整理链和媒体库同步接管。插件不增加独立探索或订阅导航。媒体库目录、智能助手、TMDB、媒体服务器和链接权限无需在插件中重复配置。

插件工作台只负责诊断、排队和状态，不内置 m3u8 播放器。你已有 Emby 时，只需按 MoviePilot 原生媒体服务器设置完成映射，插件会沿用已启用的媒体服务器并自动请求同步。
